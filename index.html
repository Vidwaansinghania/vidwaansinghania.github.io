The investment committee set

Four finance roles run in order: the analyst writes a thesis, the risk officer tries to break it, and the portfolio manager decides whether it gets capital. The macro analyst sets the context.

  • Builds the case

    Buy-side equity analyst

    Fundamental research on one public company: business model, moat, financial quality, valuation, risks and catalysts. It ends in a probability-weighted view, a confidence score out of ten and a position suitability call.

    Skill on GitHub

  • Attacks the case

    Chief risk officer

    Starts from the assumption that the thesis is wrong and works to prove it: lists how the assumptions fail, models the worst realistic outcomes, then gives a drawdown estimate and a risk rating.

    Skill on GitHub

  • Sets the regime

    Macro analyst

    Sorts the economy into one of six regimes from rates, inflation, growth, liquidity, credit and policy, then works forward to sector and factor positioning. It does not pick stocks.

    Skill on GitHub

  • Sizes the position

    Portfolio manager

    Takes the analyst's expected return, the risk officer's downside and the macro regime, checks correlation with what is already held, and turns them into a position size.

    Skill on GitHub

Study, vault and GitHub tools

  • Study

    Lecture notes builder

    Merges a lecture transcript and the slides into one exam-ready note, filed in the right Obsidian course folder. Skipped slides are marked and anything the recording garbled is flagged.

    Skill on GitHub

  • Study

    Timetable to ICS

    Converts a class or exam timetable into an .ics calendar file. A bundled Python script generates the calendar, re-reads it and checks every event against the source before handing it over.

    Skill on GitHub

  • Obsidian

    Vault health check

    Audits an Obsidian vault with a read-only script for orphan notes, broken links, duplicate names, unused attachments and stale index notes. It applies the unambiguous fixes and asks before anything destructive.

    Skill on GitHub

  • Obsidian

    PDF to Profile note

    Turns a personality report, assessment or study guide PDF into a short note with every claim cited to a page, and flags conflicts with what the Profile already says.

    Skill on GitHub

  • GitHub

    Project README publisher

    Turns a project's Obsidian notes into tab-style GitHub documentation and publishes it on a branch through a pull request. It never pushes to main.

    Skill on GitHub
