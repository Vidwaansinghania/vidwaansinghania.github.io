Work

Multi-agent equity research

From June to October 2026 I wrote equity research on my own, then built a version of the same process run by ten Claude agents. Four gather evidence, one values the company, a bull and a bear attack that value with numbers, a judge makes the call, a risk agent checks it against my portfolio and a writer produces the report.

I ran both on six companies and they agreed on five. The agents were more useful as auditors than as a second opinion: they caught a beta taken from the wrong company and a currency cost that made one of my buy instructions lose money. A run cost $71 to $88 in API fees.
